# Data sources and provenance

| File | Origin | Real students? | Used for |
|---|---|---|---|
| `raw/demo_responses_SYNTHETIC.csv` | Provided by the project owner (60 rows x 28 cols) | **No. All 60 rows are synthetic** (`SYNTHETIC` column is the constant "SYNTHETIC - NOT A REAL STUDENT") | Demo accounts, fitting the unsupervised latent model, evaluation of invariants |
| `processed/profiles.json`, `profiles_encoded.csv`, `data_report.json` | Generated by `ml/build_dataset.py` (raw file untouched) | No | Same |

Every processed record carries `origin=synthetic_demo`, `is_real_student=false`, `record_id=SYN-nnn`.
The ~10 real Bennett Google-Form responses are not in this project. If you add them, tag them `origin=real_bennett`
and keep them out of any public demo seed.

The CSV column "How compatible are you with your CURRENT roommate overall?" is **empty (0/60)**: there are no labels.

## External datasets researched (none are used for training)
| Dataset | Relevance | Verdict |
|---|---|---|
| OpenPsychometrics IPIP-FFM Big Five (~1.0M responses; also on Kaggle as `tunguz/big-five-personality-test`) | Individual Big Five item responses | Public, but **no roommate/pair labels** and not linkable to Bennett students. Not used. Optional fetch script provided but **not run** here (download domains were blocked in the build sandbox, so availability and licence terms were not verified first-hand). IPIP items themselves are public domain. |
| OpenPsychometrics HEXACO / 16PF / Grit sets | Other personality inventories | Same limitation. Not used. |
| Published roommate studies (Roommate Relationship Scale, Frontiers in Psychology 2022; CCI-R, IJIP 2023; a CRF roommate-assignment paper on arXiv) | Describe measures and findings; pair-level data are not openly downloadable | Background reading for the rule design only. |
| Dublin Business School MSc thesis on ML roommate compatibility (2024) | Similar goal; private data | Not available. |

Conclusion: no public dataset with real roommate-pair outcomes was found, so a supervised model cannot honestly be trained.
